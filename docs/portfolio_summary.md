# Portfolio summary

ClauseForge is a production-oriented legal NLP engineering project covering a
deterministic CUAD data pipeline, leakage-safe 41-category evaluation, classical
baselines, LoRA/QLoRA experiment and checkpoint infrastructure, and a strict
FastAPI inference boundary. It includes exact taxonomy validation, synthetic
robustness tests, an isolated SEC EDGAR OOD pipeline, merge/AWQ/GGUF preparation,
versioned caching, honest load-test tooling, containerization, CI/CD, structured
logging, metrics, rate-limit interfaces, and release operations.

The work demonstrates reproducibility and system boundaries rather than a final
accuracy claim. GPU feasibility and a short T4 pilot are documented; final
large-model training, rank selection, held-out evaluation, quantization, and
deployment benchmarking remain compute-dependent and incomplete.
